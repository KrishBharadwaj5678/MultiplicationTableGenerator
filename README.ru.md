## <img src="https://github.com/KrishBharadwaj5678/MultiplicationTableGenerator/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/MultiplicationTableGenerator.git
```

### 2️⃣ Переход в директорию проекта

```bash
cd MultiplicationTableGenerator
```

### 3️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4️⃣ Запуск приложения

```bash
streamlit run app.py
```
