## <img src="https://github.com/KrishBharadwaj5678/MultiplicationTableGenerator/raw/main/assets/readme/gettingStarted.gif" width="35"/> Como Começar

### 1️⃣ Clone o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/MultiplicationTableGenerator.git
```

### 2️⃣ Acesse o Diretório do Projeto

```bash
cd MultiplicationTableGenerator
```

### 3️⃣ Instale as Dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Execute a Aplicação

```bash
streamlit run app.py
```
